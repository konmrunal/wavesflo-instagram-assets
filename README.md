# WavesFlo Instagram assets

Rendered 1080x1350 cards for the `@waves.flo` Instagram calendar.

This repository exists only to give the images a public HTTPS URL that Buffer's
fetcher can reach. Instagram re-hosts media once a post publishes, so these
files need to stay reachable until the last scheduled post goes out.

Generated by the renderer in the `wavesflo-instagram` repository. Filenames
carry a content hash, so editing a card produces a new filename rather than
changing an existing image under a post that already references it.

Do not edit these by hand.
